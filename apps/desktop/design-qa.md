## 图形与覆盖

- 新绘图的轮廓、留白和材质在列表尺寸下清楚；原有品牌优先后，Pixi Painter／Saier 与 FC 使用各自的正式图形，生成版本保留为候选。
- 28 个默认图标覆盖线上与离线目录：17 个正式品牌、11 个新绘桌面变体，中央清单另保留 5 个候选版本。
- 深浅色探索页 1280 × 840 已截图；全部应用的顶部、中段、底部三张截图完整覆盖当前线上 25 个应用。
- 25 项正常时均解码为 256 × 256，显示盒为 56 × 56 CSS px，无 emoji 回退、破图、横向溢出或新增布局问题。
- 实际图片 URL 均来自固定 COS 清单，`no-referrer` 生效；页面异常、Console 错误和非预期资源失败均为 0。

## 失败与切换

- 单独隔离配置人为阻断一个图标请求，回退后的 56px 图标盒与 85px 行位置、宽高完全相同。该人为失败作为预期记录。
- 受控本地目录 fixture 使用同一文档 ID 执行空调 → 做菜 → 空调；旧空调 DOM 节点触发错误后，新图片仍可见且成功解码，未被旧节点误伤。
- 实际返回的 CSP 仍仅为既有 COS Origin 提供 `img-src` 许可，脚本、API 与 frame 策略没有扩大。

## Design 适配

- 已发布 `@yunlefun/ui@0.0.6` 提供品牌、语义状态、间距、阴影与动效；桌面中性表面保留浅灰／炭灰的层次。系统字体无新增网络请求，theme aliases 实际解析正确。
- 216px 侧栏、52px 工具栏、56px 图标不变；800 × 600 关于页与内容区无横向溢出，单列与双列奇数列表分隔正确。
- 浅色选中导航 hover／active 前景已修正，文字对比度实测 5.63／5.24；深色为 7.24／6.65。精选按钮 focus 改到按钮内侧，default／hover／active 下焦点环与底色对比均至少 4.85。
