# iOS 云应用分享卡片

应用详情右上角「分享应用」和云应用运行时「更多操作 → 二维码分享卡片」打开原生分享页。支持随系统外观的浅色／深色预览、「分享或存储卡片」与「分享应用链接」。工坊与作者版本继续分享其所属工坊或作者主页。

卡片读取现有 `CloudApplication` 公开目录投影：`GET /api/apps/public`、`GET /api/apps/public/{marketShortName 或 ID}`。包含应用图标、名称、简介、网站二维码和 YunLeFun 标识；主题色仅用于背景局部光晕。图标复用公开图标清单、深色变体、SVG 解码与缓存；无法载入时明确提示并允许重试，导出使用备用图标。

卡片使用同一份 SwiftUI 合成预览和导出，PNG 尺寸 **1080 × 1620**。内容自上而下居中：应用图标、名称、最多两行简介、大二维码、`扫码打开 · {websiteUrl host}`、`云乐坊 YunLeFun`。底部仅保留两级小字。二维码白色区域宽度占画布 44.4%，四周保留完整静区。

导出通过中性暗色渐变、柔和折射光带、局部主题微光、双层薄高光边缘和接触阴影固定磨砂玻璃观感，避免依赖无法稳定离屏导出的系统 backdrop glass。iOS 26 起的操作按钮使用原生 Liquid Glass，较旧系统使用系统 bordered 样式。卡片作为固定画布排版，编辑页的控件和说明遵循动态字号并允许滚动。

主题色只接受 `#RGB` 和 `#RRGGBB`，非法值回退 `#7898B6`；颜色只用于局部光晕。图标失败时回退 emoji，再回退中性图标占位。

## 单个 slug 预览与目录导出

分享页左上角「分享卡目录」提供：

1. 输入公开 slug（如 `dayun-kicker`）或应用 ID，点「预览应用」，直接读取公开详情接口。
2. 选择浅色、深色或深浅两套，生成当前应用卡片；打开「导出全部公开应用」后生成完整公开目录。
3. 点「存储目录到文件」，通过系统文件选择器保存独立目录。

目录包含 `{publicKey}-{light|dark}.png` 和 `manifest.json`，清单记录应用、原始网站、外观、像素尺寸、图标回退和失败项。批量过程串行刷新每个应用详情，支持进度与取消；缺失有效网站或已经停止公开的应用列为失败，不伪造二维码。全部失败时不留下空导出目录。

生成过程使用任务独占临时目录。失败／取消会回收未完成目录；系统复制期间保持目录所有权，复制完成和关闭目录页时显式回收，最终持有者释放时另有兜底清理。单元测试包含部分写入后的取消清理，不删除既有用户文件。

## 二维码与接收路径

- 二维码严格编码原始 `websiteUrl`，保留 query、fragment，不替换为 `launchURL` 别名或市场链接。只允许完整 HTTP(S) 网站地址；缺失或无效时显示错误，链接分享仍可使用。
- Core Image 编码真实二维码，读取其数据矩阵后绘制「柔和连点」：相邻模块使用同一条填充路径，仅软化外露转角，三个定位框统一圆角，时序模块保留形状。使用 M 级纠错、四模块白色静区；高分辨率绘制后缩小以保持曲线清晰。深色卡片同样保留白底黑码，不染色、反色或覆盖图标。
- 云乐坊内扫一扫识别到网站时，若完整网址唯一匹配公开目录记录，则额外显示「在云乐坊中查看」；其他网址保留浏览器入口。应用权限仍由原有详情／获取流程确认。
- 「分享应用链接」沿用 `https://apps.yunle.fun/app/{publicKey}`。项目已经包含正式 App ID 的 AASA 和 Associated Domains；有 App 时可通过系统 Universal Link 进入应用详情，没有 App 时进入网页详情，网页提供主动打开云乐坊及在线体验入口。
- 系统相机扫描卡片时遵循二维码里的应用网站地址；任意第三方网站无法仅凭云乐坊的 AASA 自动拉起云乐坊。若将来要求每张卡片都经落地页分流，需要明确把二维码内容改为云乐坊分享链接，或由每个网站配合关联域名。

## 验证

2026-11-04 复用现有 iPhone 15 Pro / iOS 27.0（`738191D2-2B9B-4A64-BDB0-9C788BEABAFC`），未新建或擦除模拟器：

- 22 项分享卡、目录导出、图片扫码及路由测试通过：完整浅深 PNG、缩至 540 × 810 的 70% JPEG、长名称／简介、query／fragment、非法主题色回退、无效地址、网址唯一匹配、作用域隔离、详情刷新、图标失败、清单、路径边界及取消清理。
- 2 项原生 UI 旅程通过：应用 URL → 详情 → 分享页 → 切换外观 → 系统图片分享面板，确认「保存图像」可用；另从 slug 预览生成目录，通过系统「我的iPhone」实际保存并收到成功回调。
- 独立 `YunleFunLiveValidation` Scheme 的 2 项 `ApplicationShareLiveTests` 只读检查真实目录、单应用接口、在线图标和目录产物。「暴力电驴」深浅样张，以及暴力电驴／云空调的批量深浅 PNG 均能解码为接口中的 `websiteUrl`。日常 Scheme 不依赖线上图标网络状态。
- 网页 TypeScript 检查及修改文件 ESLint 通过；网页两个入口另行使用手机／桌面浏览器验证。

本次不上传 TestFlight、不部署网页。首版导出 PNG；正式签名安装的 Universal Link、硬件相机、iPad 系统分享／存储面板及实际照片写入仍需设备验收。
