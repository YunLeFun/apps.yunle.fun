# 云居大字体与原生操作入口

本轮继续 M1 / M3 的逐页 UI 验收，以系统动态字体、列表和导航组件适配辅助字号，保留 iOS 16 下限。

## 行为

- 普通字号保留云居自适应图标网格。辅助字号改用系统 `List` / `Section`，每个应用仍是同一个打开按钮，保留上下文菜单中的详情、常用、移除与结束能力。
- 共用 `ApplicationRow` 在辅助字号下改为纵向排版，图标不挤占正文宽度；名称、说明和访问条件完整换行。普通字号保持紧凑横排与两行说明。
- 工具栏保留助手、添加和选项三个原生入口。普通字号用系统 `Menu` 呈现扫码、编辑、同步和运行列表；辅助字号用原生导航列表页，提供相同操作并保留系统返回。
- 空云居和本地读取失败状态使用系统 `ScrollView`，内容超出屏幕时仍可滚动访问添加 / 重试按钮。
- 云居打开按钮另外提供访问条件的 accessibility value；应用图标保持装饰性隐藏，避免重复播报。此改动没有改变安装、常用、排序、账号或付费权限。

根据 [Apple 动态字号接口](https://developer.apple.com/documentation/swiftui/dynamictypesize/isaccessibilitysize)选择布局，沿用系统 `NavigationStack`、`List`、`Label`、`Menu` 与 sheet；没有自绘导航栏或缩小字体来容纳内容。

辅助字号改用选项列表页后，同一实际旅程完成选项 → 扫码 → 关闭 → 返回云居 → 添加并切换工坊，执行约 18 秒。专项 **3 项通过**，无跳过或构建诊断：`test_sim_2026-10-16T10-27-02-391Z_pid91503_98dcd50f.xcresult`。
