# 云居空态、同步与运行会话

2026-10-17，后续验证仅使用 iOS 模拟器；沿用系统 ScrollView、List、NavigationLink、ProgressView 和按钮，不缩小动态字号。

## 问题与处理

原云居空态绕过了同步状态区域，已登录账号的读取进度、失败与冲突会被普通添加引导掩盖。空态还要求运行会话数为零；移除最后安装项后，保留的暂停会话令页面进入没有任何应用分组的分支，主内容成为空白。

空云居和已有内容现在共用同步状态。后台同步时，右上角“云居选项”的省略号在原有尺寸内显示系统转圈，按钮仍可打开菜单；VoiceOver 通过按钮的状态值读取“正在同步云居”。进度不再占用内容行，避免挤动应用。主动下拉刷新使用系统刷新指示器，期间不重复显示导航栏转圈。失败可直接重试，冲突进入既有比较 / 选择页面；关闭自动同步且尚未读取云端时，显示“尚未同步”并提供手动操作；自动同步启动前不插入这个临时提示。关闭自动同步或云同步的偏好保持，不自动上传、选择版本或改变账号数据。原有存储错误处理与编辑模式保持。

只要有会话，主内容显示紧凑的“正在运行”原生导航入口，继续保留原菜单入口；安装列表为空时同时显示“去工坊看看”。运行列表在最后会话结束后显示原生空态。移除安装记录仍不结束浏览器，会话恢复 / 结束继续交由已有运行时处理。
