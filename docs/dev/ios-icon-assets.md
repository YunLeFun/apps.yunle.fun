## 选择与呈现

目录、云居、详情和发布编辑预览共用原生图片管线。完整图标优先于透明主体，再回退旧 Logo 和原有 emoji / 首字。深色环境优先选 `darkSrc`，失败后可回退浅色资源；加载失败也会继续尝试其余来源。

完整图标保留原背景，不另加实体底板；透明主体采用系统语义底色，保持文件自身的安全区，不在上传标准化后再次缩小。父级统一裁切原生连续圆角。图标本身对 VoiceOver 隐藏，由所在应用行或操作提供语义，避免重复朗读。

上传得到的 `cloud://` 仅按同仓库显式配置的环境、存储源和已公开路径转换。允许规范的 app-icons 与 avatars 路径，不猜测其他环境、私有路径或任意存储桶。当前公开路径的过期签名可去除；其他 HTTPS 图片的查询参数保持原样。此策略与 Web 的公开媒体解析规则一致，不需要把宿主令牌发给图片服务器。

## 解码与缓存

- 固定使用 [SwiftDraw 0.29.0](https://github.com/swhitty/SwiftDraw/releases/tag/0.29.0)，通过 Core Graphics 把独立 SVG 绘为图片；普通图片由 ImageIO 按目标像素降采样。标准 SwiftUI `Image` 负责最终显示，无须给每个图标建立 WebView。依赖版本与修订写入 `Package.resolved`，原许可证包含在 App 资源中。
- 图片请求使用临时、无 Cookie / URL 凭据 / 磁盘缓存的会话；没有宿主 Authorization。仅允许无 URL 账号密码的 HTTPS 源和重定向；用流式读取限制响应为 5 MB。
- 内存缓存限制 32 MB / 128 项；同 URL 与目标尺寸的并发读取合并；最多同时处理 4 项。失败短暂退避，避免列表滚动不断重试坏地址。视图取消后不展示迟到结果，共享请求仍可在限制内完成并缓存；更细的共享请求取消与完整滚动 / 内存测量仍待性能阶段验证。
- 装饰性的 emoji / 首字缺省图标用原生 ImageRenderer 生成图片，避免把固定尺寸的品牌图标当作动态字号正文审计；应用名称与摘要仍是真实、可缩放的 Text。缺省图按文字、尺寸、显示倍率与明暗外观区分，另有 8 MB / 128 项内存上限，保持透明背景与原图色彩。没有提交生成媒体；原始裁切与复测见[辅助功能审计](./ios-accessibility-audits.md)。
- SVG 限制 2 MB、节点 / 深度 / 引用展开预算。拒绝 DTD、实体、脚本、外链、嵌入图片和递归引用；CSS 样式表中的资源 URL 暂不支持，以免绕过元素引用预算。支持本轮目录使用的路径、形状与渐变；不能据此声称支持所有 SVG 特性。异常内容回退其他资产。
- 编辑器从文件选择 SVG 后复用同一解码器，继续生成 1024×1024 PNG；透明主体仍按既有约 80% 安全区标准化。真实账号上传与重新读取尚未联调。

## 实际证据与缺口

iOS 27 日常测试 **141 项通过**（140 单元 / 集成 + 1 UI），本轮新增 9 项图标测试，覆盖公开云图标重开、深色选择、SVG 方向 / 渐变、危险资源拒绝、上传标准化、并发合并、失败回退、响应限制和浅深色渲染样例。样例使用隔离测试数据，不代表真实账号成功。

iOS 18.6 的图标 / 目录 14 项通过。独立 `YunleFunLiveValidation` Scheme 直接读取线上公开目录与图片；三款现有 SVG（今天来做菜、云笺、游乐场）的实际解码在 iOS 27 / 18.6 均通过，并保留 PNG 附件。该 Scheme 包含联网检查，独立于日常测试：

```sh
xcodebuild -project apps/ios/YunleFun.xcodeproj -scheme YunleFunLiveValidation \
  -destination 'platform=iOS Simulator,id=SIMULATOR_UUID' \
  -derivedDataPath /tmp/yunlefun-ios-live CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- \
  -parallel-testing-enabled NO test
```

全目录资产检查 **仍失败**：本轮 9 个带图片来源的作品中 7 个能读取并解码，纸星与 SMap 的目录图标 URL 返回 404。保留 `testPublishedBrandIconsUseRealAssets` 与失败 xcresult，不能用三款成功 SVG 代替全目录验收，也没有静默更改线上目录资料。

iOS 27 / 18.6 的真实做菜详情页旅程均通过，已人工核对品牌图标、背景和圆角；浅深色隔离样例也已查看。真实详情页截图、浅深色样例、解码图片、生产只读探测与测试路径保存在本聊天 `ios-native/icon-assets` 附件。硬件运行、完整图标格式与系统辅助设置矩阵、真实上传重开和性能基线仍未完成，整个 Goal 保持进行中。
