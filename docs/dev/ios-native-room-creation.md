# 原生创建房间（2026-11-01）

原生开发版 0.2.0（6）提供「寻乐 → 创建房间」及公开房间列表中的创建入口。游戏卡片与最近记录中的联机操作预选相应游戏。系统 Form、Picker 与 Toggle 支持选择游戏、查看 4 人容量并设置是否公开，默认私密；星纸未开放的在线玩法不会进入原生创房选项。

原生登录成功后展示表单，取消可返回寻乐。提交复用注册的 `play-web` / `play` SSO：原生授权生成 PKCE 一次性 code，交换身份断言，随后通过 `/v1/session/exchange` 建立只驻留内存的 Play API 会话，再 POST `/v1/rooms`。请求明确携带 `Origin: https://play.yunle.fun`、公开设置与稳定的 `Idempotency-Key`。API Cookie 不写入 WebKit 或系统 Cookie 存储，临时会话随后单独撤销，App 登录保持不变。进入所创建房间继续沿用既有原生房间邀请及游戏容器流程。

账号身份代次与请求取消共同约束待办操作，写入前再次核验账号。网络结果不明时，以分账号的本地创房记录保留原编号、游戏及公开设置；重开页面仍重试同一操作。成功结果保存房间号，供返回；「创建另一个房间」才开始新操作并恢复默认私密。记录不保存凭据，也不授予席位。已有 Play 会话占用时，创房前提示返回或结束原来的房间，保留原有恢复入口。
