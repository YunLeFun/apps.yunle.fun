# 原生云应用导航栏

独立 iOS 客户端使用 `UINavigationController`、`UINavigationItem` 和 `UIBarButtonItem` 承载云应用导航。系统管理标题、按钮分组、材质、安全区和尺寸适配，应用不自行绘制顶栏背景。采用 Apple [标准组件的 Liquid Glass 适配](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)与 [UIKit 新设计指南](https://developer.apple.com/videos/play/wwdc2025/284/)。

## 行为

- 导航标题通过系统标题菜单进入原生应用详情。菜单采用 iOS 16 起可用的 `titleMenuProvider`。
- 返回按钮跟随真实 WebKit 历史更新，网页侧滑返回继续使用 `allowsBackForwardNavigationGestures`。收起与更多操作使用系统导航项。
- 导航面采用系统配色；应用主题色保留在进度条和网页中。旧 Capacitor 宿主继续使用原有主题色标题栏与布局。
- `hideTitleBar` 仍允许网页延伸到屏幕顶部。收起、返回和更多转为 44pt 原生浮动按钮，iOS 26 起使用 `UIButton.Configuration.glass()` 与 `UIGlassContainerEffect`，早期系统使用语义配色的系统按钮回退。
- 浮动容器仅响应按钮区域，按钮之间的网页仍可交互。`showTitleBar` 恢复系统导航栏和网页视口。

## 会话与协议

会话池将 WebView 和导航容器作为一个会话保留。收起后复用同一导航容器及 WebKit 历史；结束、身份重置和内存淘汰同时释放两者。宿主授权页继续由同一个浏览器控制器发起，不向网页传递宿主令牌。授权与延迟菜单动作同时检查导航容器的转场状态；真实 UIKit 转场专项确认容器仍在窗口中、但正在退出时不能开始登录。

`getEnv` 的字段保持原有结构，坐标仍相对 WebView 视口。系统导航栏可见时，`capsuleRect` 返回视口上方的整条导航栏避让区域，避免依赖系统导航按钮内部视图；隐藏后返回实际浮动更多按钮的矩形。显隐调用先同步布局，再回复 JS，调用方可立即重新读取几何。

## 会话层级与连续打开

新增真实 UIKit 层级测试复现了一个清理缺陷：云应用上方有原生详情及子弹层时，从导航容器调用 `dismiss` 只关闭了它呈现的弹层；运行时虽已移除会话，WebView 仍留在窗口。结束和身份重置现从导航容器的呈现者关闭整个层级，原生关闭回调由运行时统一处理；收起也关闭同一层级，并继续保留浏览器与历史。结束不会删除云居安装记录。

前台只保留一个云应用容器。打开另一应用时，先取消旧页面的待决授权并完成整个层级的退出，再从主窗口根控制器呈现目标会话。连续请求只执行最新一个；转场完成回调检查自身标识，身份重置清空待打开请求。旧控制器的关闭或收起回调不能结束替换会话或把旧账号应用重新加入列表。

全屏呈现会暂时将主界面的锚点视图移出窗口。运行时弱引用此前确认的窗口，并核对锚点仍属于该根控制器；因此既可从作者作品等弹层发起切换，也不会通过已脱离界面的锚点访问旧窗口。应用 URL 或访问范围变化时，旧会话继续按原约定替换。

新增 `NativeRuntimeSessionTests` 10 项，覆盖多层弹窗的身份重置、结束、收起恢复、跨应用复用、连续打开、重置取消排队、迟到回调、URL 替换和失效锚点。最终日常回归 228 项（227 单元 / 集成 + 1 UI）通过。首次 URL 替换检查误将仍在退出的同 ID 页面当成目标，等待条件补充 URL 与退出状态后通过；初始清理缺陷及中间失败结果均保留。

真实页面旅程另发现作者作品列表的导航缺陷：点击作品后导航栏变化，但内容仍停在作者列表，无法执行打开操作。作者作品现使用带明确详情目的页面的原生 `NavigationLink`。修正后的“云空调 → 更多 → 作者 → AI 春联详情 → 打开 → 作者 → 云空调详情 → 恢复 → 分别结束两会话”旅程通过，实际截图核对了原生详情与恢复后的网页，收起入口仍唯一。该旅程未输入账号或发起购买。

同轮既有的系统标题菜单 / 详情返回、收起恢复结束、完整菜单和 AI 春联访客授权取消四条旅程也通过；它们在作者作品导航修正前执行，与修正后的跨应用旅程分开记录。四条结果为 `test_sim_2026-10-16T07-01-45-878Z_pid92585_33b373f9.xcresult`（新增跨应用项当时失败，整次运行仍为失败），跨应用修正后为 `test_sim_2026-10-16T07-06-12-596Z_pid92585_defdcda7.xcresult`（1 项通过）。

作者作品导航修正后的最终日常结果为 `test_sim_2026-10-16T07-07-57-005Z_pid92585_f90df852.xcresult`（228 项通过）；旧兼容 Release 模拟器编译也通过，保留既有 3 条 Pods 脚本提示。详细路径、源码摘要与各次结果保存在仓库外 `ios-native/runtime-sessions/verification.json`。会话专项使用隔离账号对象与保留域名，不代表真实登录或逐应用 SSO 隔离通过；成功登录后的会话保留仍按上文待复验。
