# 截屏后的反馈入口

2026-10-24：为原生客户端增加可关闭的截屏反馈快捷入口，复用既有 `FeedbackView`。本轮不读取相册、不捕获页面图像、不上传截图，也不更改诊断上传协议。

> 2026-10-27：通用反馈已增加手动选择截图的能力，见[截图反馈契约](./ios-support-feedback.md)。截屏事件仍不自动附带图片；TestFlight 版本优先使用 Apple 的反馈，不再展示本 App 的胶囊。

> 同日新增[系统分享反馈扩展](./ios-share-feedback.md)：正式版用户可以从系统截屏预览或照片的分享菜单选择「云乐坊」，打开「反馈给云乐坊」表单。该入口读取用户主动分享的图片，复用支持中心；TestFlight 仍优先引导官方反馈。

## 用户行为

- 默认开启；在「我 → 设置 → 反馈 → 截屏后显示反馈入口」持久关闭或重新开启。
- 收到系统截屏通知后，仅在所属窗口可交互时显示右下方「反馈问题 ×」胶囊，位于底部导航与键盘上方。没有遮罩，不切换页面、不改变 key window、不主动播报或抢焦点。
- 普通展示累计 8 秒。连续截屏不叠加、不延长展示时间；自动消失或点入反馈后冷却 30 秒。主动关闭后，本次启动期间不再提示；设置关闭后重新开启可解除该抑制。
- 临时 inactive 时隐藏并暂停计时，恢复活跃后再展示；待处理截图最多保留 120 秒。进入后台、切换身份、关闭设置或打开反馈页时清除待展示提示。辅助功能聚焦在提示按钮期间保留操作机会。
- 只允许主页面与全屏云应用导航容器上的提示；系统选择器、登录、授权、普通 sheet、警告框与转场期间不显示提示。
- 点击后才呈现已有原生反馈页，关闭反馈回到原页面；从这里登录时，先将登录请求及草稿转交根级流程，成功沿用已有登录续接，取消后恢复同一访客的草稿。

## 实现边界

`ScreenshotFeedbackPromptState` 保存启用、去重、冷却和剩余可见时间；`ScreenshotFeedbackCoordinator` 监听截屏与 scene 生命周期，将普通胶囊子视图挂在所属 `UIWindow`，不创建额外 key window。`ScreenshotFeedbackAnchor` 保留窗口弱引用，因为全屏 UIKit 云应用会临时移除根 SwiftUI anchor 的 view。

胶囊使用当前呈现控制器内容视图的 `keyboardLayoutGuide` 定位，切换呈现控制器时重建约束，并受窗口安全区限制。不能只断言按钮在屏幕内：验收截图曾发现窗口自身的键盘 guide 未得到预期布局，导致按钮靠上；回归测试同时断言无键盘时按钮位于页面安全区底边上方 80 pt。

Apple 的 [`userDidTakeScreenshotNotification`](https://developer.apple.com/documentation/uikit/uiapplication/userdidtakescreenshotnotification) 在截屏完成后发出，没有 `userInfo` 或图片。提示在该事件之后创建；若用户在提示仍可见时再次截屏，画面可能包含提示本身。公开接口无法在截图前可靠隐藏它，第一版通过合并与冷却减少干扰。

短延迟仅用于避开即时转场，不能作为系统截图预览已关闭的证据；显示与计时还受所属 scene 的活跃状态约束。不同 iOS 版本的系统截图预览通知时序仍需真机核对。

## 验证记录

本轮使用已有空闲的 iPhone 18 Pro / iOS 27 模拟器（`4502D5E9-9630-4AF0-9050-3C9109139FD0`），保留其数据，不创建、擦除或删除其他任务设备。构建与验收产物放在任务独占临时目录，结束后回收可重建产物。

验收结束后该设备处于 Shutdown，未创建临时模拟器；本轮 iOS 临时构建、测试包、结果包和截图已回收约 474 MiB，保留原有工程构建目录及共享依赖缓存。

- 首轮 Debug 模拟器编译通过；两条既有 `CrossAppAuthorization.swift` actor 转换警告与本次改动无关。
- 最终 Debug 模拟器验收通过：15 项提示状态测试、11 项窗口集成测试与 13 项既有反馈登录测试，共 39 项、0 失败。覆盖延迟、合并、冷却、关闭、设置开关、模态避让、窗口触摸、全屏导航返回和取消登录后的草稿恢复。
- 窗口测试注入截屏、scene 与辅助功能焦点通知，点击胶囊的真实 UIKit 控件；反馈页关闭验证复用的关闭处理器，没有模拟点击 SwiftUI「完成」按钮。浅色、深色最大辅助字号和已有反馈表单分别留取截图检查。
- 尚未进行真机系统截屏、全屏截图预览返回时序或完整 VoiceOver 旅程验证。注入通知和自动化取图只验证状态、路由与布局，不代表硬件截屏行为已经验收。
