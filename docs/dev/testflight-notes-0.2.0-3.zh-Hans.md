# 0.2.0 (3) 中文 TestFlight 测试说明

本次修复历史版本提交人与当前所有者不同时，“我的应用”整页无法载入的问题。历史提交记录保留，作品所有权及新版本保存仍严格核验。补充 TestFlight 测试钱包隔离与交易环境检查。

重点回归：

1. 启动后检查四个 Tab、目录、分类、搜索、详情和免费应用获取。
2. 先用原有安装更新，确认云居应用、排序和设置保留；不要先卸载 App。
3. 登录、退出、切换账号和重启；检查各账号云居、钱包和作品不会串号。
4. 云同步成功、断网提示、重试及冲突处理；操作前保留自己的云居备份。
5. 云应用原生登录与授权：确认、取消、重试、收起、恢复和结束；检查网页身份一致。
6. “我的应用”核对历史作品列表、编辑字段、本机草稿和预览；确需保存或投稿时，确认目标是自己的测试作品。

支付范围与限制：

- TestFlight 交易属于 Apple Sandbox，不应增加或扣减正式云币与会员。
- 本版自动识别测试 receipt，使用隔离测试钱包。当前专用 Sandbox 服务尚未部署，钱包 / 购买可能显示不可用；请验证提示与重试行为，不要求反复发起交易。
- 真实购买、恢复到账、待批准、失败补单和退款**尚未通过**。待测试服务就绪后，使用指定测试账号完成购买 → 账户读取 → 重启恢复 → 断网重试 → 退款，并核对正式权益始终不变。
- 不从本机“已完成交易”推断新增到账。未确认交易应继续保留，不切换账号领取。

本轮以模拟器为范围。相机、触觉、锁屏保护、跨设备 iCloud 和真机覆盖升级仍待验；iOS 27.1 Duo、iPad、最低系统与完整无障碍矩阵未完成。反馈请附版本、系统、操作路径和错误提示，日志上传前先预览，避免包含密码、令牌或个人资料。
