# 0.2.0 (4) 中文 TestFlight 测试说明

本次加入云居工坊快捷切换，修复已登录账号在个人工坊详情中仍被“需要登录”阻止打开的问题。详情操作采用系统 Liquid Glass，管理后台与支持中心复用在线图标登记。本版同时包含前次候选的历史作品修复与支持中心集成。

重点回归：

1. 在云居切换个人云居、自己的工坊和已加入工坊。选择云乐坊私有工坊后，核对管理后台与支持中心显示及在线图标。切换不应自动安装应用到个人云居。
2. 从个人工坊进入管理后台详情，登录后打开；退出、切换账号、撤销工坊权限后重新检查。受邀、会员、付费及暂停状态仍应由服务端核验。
3. 检查详情页大字号、深浅色、打开、添加到云居、应用数据及缓存操作。
4. 同标识覆盖更新并保留原有云居、排序和设置；登录、退出与切换账号，核对云居、钱包及作品数据隔离。
5. 检查支持中心、工单详情、反馈入口、应用原生授权，以及历史作品的列表、编辑与预览。

测试边界：

- TestFlight 购买使用 Apple Sandbox。专用 Sandbox 钱包服务尚未部署，钱包与购买可能显示不可用；真实购买、恢复到账和退款尚未通过，不应增减正式权益。
- 标准 iPhone 模拟器完成本轮回归；iOS 27.1 Duo 专项仍保留前次失败记录。相机、触觉、锁屏保护、跨设备 iCloud、物理 TestFlight 覆盖升级、iPad、最低系统及完整无障碍矩阵仍待验。
- 反馈请附版本、系统、操作路径和错误提示；上传日志前先预览并移除密码、令牌与个人资料。
