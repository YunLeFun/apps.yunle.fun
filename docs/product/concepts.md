# 核心概念

## 云应用 Cloud App

**云应用**是云乐坊的核心概念。与传统的原生 App 不同，云应用是运行在浏览器中的 Web 应用，用户无需下载安装即可使用。

每个云应用包含以下要素：

| 属性   | 说明                              |
| ------ | --------------------------------- |
| 名称   | 云应用的显示名称                  |
| Slug   | URL 唯一标识符                    |
| 图标   | 支持自定义 Logo 或 Emoji，默认 📱 |
| 主题色 | 图标背景色，10 种预设 iOS 风格色  |
| 网址   | 应用入口 URL                      |
| 分类   | 所属分类标签                      |

### 图标展示规则

优先级：`logo` > `emoji` > 默认 emoji `📱`

```text
有 logo URL → 展示 logo 图片（圆角矩形裁剪）
无 logo    → 展示 emoji 字符
无 emoji   → 展示默认 📱
```

背景色使用 `themeColor`，未设置时默认 `#007AFF`（iOS 蓝）。

## 安装与桌面

用户在**工坊**中发现云应用后，可以「安装」到自己的**云居**桌面。安装并不是真正下载，而是将应用添加到用户的桌面配置中。

桌面配置包括：

- **网格应用** — 主桌面上的应用列表，支持分页和排序
- **Dock 应用** — 底部固定栏的常用应用（最多 4 个）
- **最近使用** — 自动记录最近打开过的应用

桌面配置存储在 CloudBase 云端，支持多设备同步。本地通过 localStorage 缓存，写入时 500ms 防抖后异步同步到云端。

```text
│                 CloudBase NoSQL              │
│  apps │ user_desktops │ featured │ weekly    │
└────────────┬────────────────────────────────┘
             │
┌────────────┴────────────────────────────────┐
│            Composables 数据访问层            │
│  useApps │ useHomeScreen │ useDiscovery      │
└────────────┬────────────────────────────────┘
             │
┌────────────┴────────────────────────────────┐
│          Pinia Store 缓存层                  │
│  homeScreenStore (localStorage + CloudBase)  │
└────────────┬────────────────────────────────┘
             │
┌────────────┴────────────────────────────────┐
│          Vue 组件展示层                      │
│  home.vue │ discovery.vue │ apps.vue         │
└─────────────────────────────────────────────┘
```
