# 寻乐 - Discovery

> 2026-10-28 新方向：应用推荐并入工坊，寻乐改为独立游戏 Tab；四 Tab 名称与顺序保留。[改造计划](./native-game-discovery.md)已启动实施，下文记录改造前的发现推荐设计，不代表当前开发版的游戏页。

寻乐是内容发现和推荐页面，帮助用户发现优质的云应用。

## 功能模块

### 1. 今日推荐

- 大尺寸渐变色卡片展示**编辑精选**应用
- 支持 `daily`（每日推荐）和 `editor`（编辑推荐）两种类型
- 卡片包含应用名称、描述、图标和主题色渐变背景

### 2. 本周热门排行

- 列表展示当周热门应用 **Top 10**
- 按周一时间戳查询，每周自动刷新
- 带排名序号的列表样式

## Fallback 策略

CloudBase 无数据时自动回退到静态常量数据（`FEATURED_APP` / `ALL_APPS`），确保页面始终有内容展示。

## 数据来源

| 数据     | CloudBase 集合  | Fallback                 |
| -------- | --------------- | ------------------------ |
| 今日推荐 | `featured_apps` | 静态 `FEATURED_APP` 常量 |
| 本周热门 | `weekly_charts` | 静态 `ALL_APPS` 常量     |

## 组件结构

| 组件                 | 职责             |
| -------------------- | ---------------- |
| `AppFeatured.vue`    | 编辑精选推荐卡片 |
| `AppWeeklyChart.vue` | 每周热门排行列表 |
