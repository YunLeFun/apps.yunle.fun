# 什么是云乐坊

**云乐坊** (yunle.fun) 是一个云应用聚合平台。用户可以在**工坊**中发现各式各样的云应用，将心仪的应用安装到自己的**云居**桌面，随时随地点击即用。

## 产品定位

云乐坊致力于打造一个**轻量、开放的云应用生态**：

- **对用户**：无需下载安装原生 App，在云居桌面管理自己常用的云应用
- **对开发者**：在工坊发布自己的云应用作品，获得曝光和用户

## 核心体验

整个产品围绕三个 Tab 页构成：

| Tab | 名称                 | 定位     | 核心功能                              |
| --- | -------------------- | -------- | ------------------------------------- |
| 🏠  | **云居** (Home)      | 个人桌面 | iOS 风格的桌面网格，拖拽排序，Dock 栏 |
| 🔍  | **寻乐** (Discovery) | 发现推荐 | 每日编辑推荐 + 每周热门排行           |
| 🏗️  | **工坊** (Workshop)  | 应用商店 | 分类浏览、搜索、安装云应用            |

## 技术栈

| 层级     | 技术选型                          |
| -------- | --------------------------------- |
| 前端框架 | Nuxt 4 (CSR 模式) + Vue 3         |
| UI 框架  | Ionic Vue + Konsta UI             |
| 样式     | Tailwind CSS 4 + UnoCSS (仅图标)  |
| 状态管理 | Pinia                             |
| 移动端   | Capacitor 8 (iOS)                 |
| 后端     | Nitro Server API + 腾讯 CloudBase |
| 认证     | CloudBase Auth + 微信登录         |
| 部署     | EdgeOne Pages（Git 集成）         |
