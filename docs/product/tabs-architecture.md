# Tab 页架构设计

云乐坊（yunle.fun）核心三个 Tab 页面的功能架构设计文档。

## 总体架构

```text
┌─────────────────────────────────────────────┐
│                 CloudBase NoSQL              │
│  apps │ user_desktops │ featured │ weekly    │
└────────────┬────────────────────────────────┘
             │
┌────────────┴────────────────────────────────┐
│            Composables 数据访问层            │
│  useApps │ useHomeScreen │ useDiscovery      │
└────────────┬────────────────────────────────┘
             │
┌────────────┴────────────────────────────────┐
│          Pinia Store 缓存层                  │
│  homeScreenStore (localStorage + CloudBase)  │
└────────────┬────────────────────────────────┘
             │
┌────────────┴────────────────────────────────┐
│          Vue 组件展示层                      │
│  home.vue │ discovery.vue │ apps.vue         │
└─────────────────────────────────────────────┘
```

## 云居（Home）- 桌面页

### 功能模块

1. **最近使用区域** — 展示最近使用过的云应用（默认 4 个，可展开查看最多 100 个）
2. **主体桌面** — 翻页式应用网格（每页 4×6=24 个），支持长按编辑模式、拖拽排序
3. **底部 Dock** — 固定 4 个常用应用，仅图标无名称，毛玻璃背景
4. **编辑模式** — 长按触发，图标抖动 + 删除按钮，点击空白退出

### 数据流

```text
用户操作 → homeScreenStore (Pinia + localStorage)
                ↓ 防抖 500ms
        useHomeScreen.syncToCloud()
                ↓
        CloudBase user_desktops 集合
```

## 寻乐（Discovery）- 发现推荐

### 功能模块

1. **今日推荐卡片** — 大尺寸渐变色卡片展示编辑精选应用
2. **本周热门排行** — 列表展示当周热门应用 Top 10

### Fallback 策略

CloudBase 无数据时自动回退到静态常量数据（`FEATURED_APP` / `ALL_APPS`），确保页面始终有内容展示。

## 工坊（Apps）- 应用商店

### 功能模块

1. **分类标签栏** — IonSegment 横向滚动，沿用现有分类
2. **搜索功能** — 防抖 300ms，从 CloudBase 正则匹配搜索
3. **应用列表** — 复用 `AppList.vue`，改为从 CloudBase 查询 + 无限滚动
4. **安装交互** — 「获取」按钮 → 安装到云居桌面
