# 扫码功能演示

## 🎬 功能演示

### 1. 打开扫码

在首页点击右上角的 `+` 按钮，在下拉菜单中选择「扫一扫」：

```
首页 → 点击 + → 选择「扫一扫」
```

### 2. 扫描界面

扫码界面包含以下元素：

```
┌─────────────────────────┐
│                         │
│    [相机预览画面]        │
│                         │
│    ┌─────────────┐      │
│    │   扫描框    │      │
│    │   ━━━━━━    │      │ ← 扫描线动画
│    │             │      │
│    └─────────────┘      │
│                         │
│  将二维码/条形码放入框内  │
│      即可自动扫描        │
│                         │
│    [✕]      [💡]        │ ← 取消 / 手电筒
└─────────────────────────┘
```

### 3. 扫描结果处理

#### 应用链接

```
扫描内容: https://yunle.fun/app/123
处理方式: 自动跳转到应用详情页
```

#### 普通 URL

```
扫描内容: https://example.com
处理方式: 在新窗口打开链接
```

#### 文本内容

```
扫描内容: Hello World
处理方式: 显示 Toast 提示
```

## 🎨 界面特性

### 扫描框设计

- 四角定位框（白色）
- 扫描线动画（绿色渐变）
- 半透明边框
- 居中显示

### 动画效果

- 扫描线上下移动（2秒循环）
- 菜单下拉动画
- 按钮点击反馈

### 响应式设计

- 移动端：260x260px 扫描框
- 平板端：自适应大小
- 桌面端：居中显示

## 📱 平台差异

### iOS

- 使用原生相机
- 流畅的扫描体验
- 自动对焦
- 支持多种码制

### Android

- 使用原生相机
- 快速识别
- 自动对焦
- 支持多种码制

### Web

- 使用浏览器相机 API
- 实时视频预览
- 需要 HTTPS 环境
- 浏览器兼容性要求

- Code 39
- Code 93
- Code 128
- ITF
- Codabar
- RSS-14
- RSS-Expanded

## 💡 使用技巧

### 1. 最佳扫描距离

- 二维码：10-30cm
- 条形码：15-40cm

### 2. 光线要求

- 充足的光线
- 避免强光直射
- 可使用手电筒辅助

### 3. 扫描角度

- 保持垂直
- 避免倾斜
- 确保码清晰可见

### 4. 扫描速度

- 保持稳定
- 不要晃动
- 等待自动识别

## 🎯 实际应用场景

### 1. 应用分享

```
用户 A 生成应用分享码
  ↓
用户 B 扫码
  ↓
自动跳转到应用详情
  ↓

```

### 2. 快速登录

```

  ↓
移动端扫码
  ↓
自动登录
```

### 3. 内容分享

```
生成内容分享码
  ↓
扫码查看
  ↓
快速访问
```

## 🔐 隐私和安全

- ✅ 仅在扫码时访问相机
- ✅ 扫码完成后自动关闭相机
- ✅ 不保存相机画面
- ✅ 不上传扫描内容
- ✅ 本地处理扫描结果
