# Web 收口与 Android 原生化

1. 当浏览器打开旧页面、已分享的链接或现有客户端请求 API 时，现有地址继续响应；官网接替对应页面后再逐条切流。
2. 当 Android 启动时，显示 Kotlin 原生的应用目录，可搜索、查看详情及试用公开免费应用；网络失败时可重试。获取、会员、登录和发布交给既有流程，直到对应原生功能完成。
3. 当云应用在 Android 内打开时，保留现有独立 WebView、返回、菜单、收起恢复以及可信主 frame 校验；需要账号授权时使用系统浏览器的 SSO 流程。
4. 当安装 JS 依赖或构建 Android 时，源码、依赖图和构建脚本无需 Capacitor / Cordova，也不把 Nuxt 产物装进 APK。
5. 现有已安装客户端和浏览器本地云居的数据需要可回退；本次不部署、不改签名或域名、不重定向旧 API，也不清空本地数据。
